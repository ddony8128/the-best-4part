TALENT LINK · 인사정보 데이터 구조

본 패키지 데이터는 예시 목적으로 생성한 합성 인사 데이터이며 실제 직원의 인사기록, 검증 완료된 증빙 또는 확정된 평가 자료가 아닙니다.
화면에서는 지원자별 인사 이력과 검토가 필요한 증빙 상태를 표시합니다.

파일 구성: index.html / applicants.js / hr_records.js / CSV 11종 / applicants.jsonl / jobs.json
실행: 압축 해제 후 같은 폴더에 있는 index.html 실행
인사정보 식별키: employee_id
지원자 건수: 250 / 마케팅 JD 지원자: 60
자기소개서: 마케팅 JD-019, JD-034, JD-045 지원자 각 3개 항목, 8줄 이상
증빙: 직접 수행·산출물·결과 정보를 담은 검토 요청 기록, 검증 완료 주장 없음

개선: hr_data_entry 코드 제거, 스킬 평가 기준 변경, 근속·직급별 KPI 2~13건, 발령 이력 1~6건 분포 반영.
주의: 합성 인사기록입니다. 평가와 증빙 확인 상태는 실제 검증을 뜻하지 않습니다.
