# TALENT LINK 디자인 시스템 (TL-DS)

토스 디자인 시스템(TDS)의 구조와 원칙을 따르고, 강조색만 **한화 오렌지**로 바꾼 체계입니다.
코드: `public/tl-ds.css` (모든 화면이 각자의 스타일 뒤에 불러옴), 기존 화면 변환: `scripts/apply-ds.mjs`

## 왜 바꿨나
- 이전 화면은 10~12px 글자와 연한 회색(#999, #aaa) 본문이 많아 "AI가 만든 화면"처럼 보이고 읽기 어려웠습니다.
- 토스는 **큰 글자, 진한 본문, 흰 카드와 회색 바탕, 테두리 대신 여백, 한 화면 하나의 주요 행동**으로 정보가 많아도 쉽게 읽힙니다.

## 원칙
1. **읽히는 크기**: 최소 13px(보조 정보), 본문 15px, 중요한 본문 17px. 본문 굵기는 500 이상.
2. **진한 본문**: 본문 grey900, 보조 grey700, 덜 중요한 정보 grey600. grey500 이하는 본문에 쓰지 않습니다.
3. **한 화면 하나의 주요 행동**: 오렌지 버튼(`.primary`)은 화면의 핵심 행동 하나에만. 나머지는 회색 면 버튼, 보조 강조는 연한 오렌지(`.accent`).
4. **테두리 대신 면과 여백**: 회색 바탕(grey100) 위 흰 카드, 둥근 모서리 20px, 그림자는 아주 약하게.
5. **기존 정체성 유지**: 한화 오렌지, DNA 첫 화면, 네이비 스캔 패널·로그인 좌측 패널은 그대로.
6. **쉬운 말 (UX 라이팅)**: 존댓말, 핵심 먼저, 필요 없는 단어 빼기. 한 문장에 판단 하나.

| 표 | 머리글 13px/600 grey600, 본문 15px grey800, 줄 구분 grey100 |

| 안내 | orange50 면, orange800 글자, 모서리 16 |

## 화면별 변환
- `scripts/apply-ds.mjs`가 각 화면의 글자 크기를 위 단계로 바꾸고(예: 10·11px → 13px, 12px → 14px), 연한 회색을 TDS 회색으로 바꾼 뒤 `tl-ds.css`를 불러옵니다.
- 이전 화면은 `ui-v1-classic` 브랜치에 그대로 남아 있습니다.
